# Controller index

Each snapshot can occupy a numbered slot. That number is its **controller index** — the pad it lights up and triggers on a connected MIDI controller such as an APC Mini.

## Editing the layout

- The grid shows every slot; filled cells hold a snapshot, and the one that's currently live is highlighted.
- **Drag a filled cell** onto an empty slot to move it there, or onto another filled slot to swap the two.
- The dropdown switches the on-screen arrangement: **Reading order** numbers left-to-right and top-to-bottom, while a controller layout (e.g. APC Mini) matches that hardware's physical pads.

Reassigning indices only changes which pad a snapshot answers to — it leaves the snapshot's stored values and its order in the Variations window untouched.
