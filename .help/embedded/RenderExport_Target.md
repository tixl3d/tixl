# Output Target

Choose **where** the file is written.

- **Folder** — the destination folder (relative to your project).
- **Filename** — the name; the extension (`.mp4`, `.mov`, `.mkv`) is set automatically from the codec.
- **Auto-increment version** — after each render, bump a version number (v01 → v02) so you never overwrite a
  previous take.

For an **image sequence** you instead set a **subfolder** and a **filename prefix** for the numbered frames.

Hover the **(?)** next to any field for a short explanation. Click below for the full guide.
