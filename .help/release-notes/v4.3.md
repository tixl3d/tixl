# TiXL v4.3 - Release Notes (WIP)



## Audio Graphs

Similar to shader graphs you can now create audio graphs. Under the hood, these are related problems because TiXL first have to collect the required and operators and then keep updating them. For this we added a new `Audio Graph Node` connection type. And similar to Raymarch Field we introduced the new [AudioBus] operator. This is huge,  because this unlocks multiple soundtracks, audio effects (e.g. [AudioReverb], [AudioDelay],  audio pipelines with side chaining and ducking [AudioLevel], [AudioDucking] etc.).

## New Project Soundtrack

With the new audio pipeline come a much more powerful [AudioClip]. This replaces TiXL's project soundtrack: Old projects will be updated automatically and their main soundtrack we be replaced with an "AutoPlay" AudioClip. This unlocks a bunch of new features such as:

- You can animate the audio volume
- Have multiple project project soundtracks
- Customize how a project soundtrack should looks.

## Editing Video and TimeClips

Okay - I admit: I hate creating release videos. So the only logical reason for this is that editing with Premiere is not fun and we need video editing capabilities in TiXL. We might have gone overboard with this one, but getting this right surfaced a lot of latent issues and feature gaps:

- Videos can now playback audio
- Clips can have local keyframes that move with their clips
- Audio- and Video-Clips can be "auto collected" by player operators without the need to manually create connections
- [VideoClip]s now have nice thumbnails
- [AudioClip]s can be displays as Volume-level and Waveform
- Clips can be duplicated with `Ctrl+D` — like splitting, the new operator is inserted tidily into the graph and pushes covered operators down
- Texture effect operators can be inserted between a [VideoClip] and its [VideoClipPlayer]
- Video clips show a preview thumbnail on hover and at their begin and end
- The audio tracks of videos are now included when rendering / exporting videos
- Audio tracks in MKV files play back correctly
- Fixed video tearing during playback and when encoding proxy files
- Improved performance when seeking outside a clip's source range
- Rendering custom ranges with audio and exporting image sequences works reliably again, and video render-export got faster

## Source Region Editing

The Timeline ruler can now display the extend of the source data. This source region can be dragged for intuitive slip edits.

## Improve Project Settings

We cleaned up the design and structure of the the *Project Settings* window.



## Asset Library

- Asset files can be deleted from the Asset Library (they're moved to the Windows recycle bin)
- Dropping a file folder into the editor lets you create external folder references
- Broken asset folder references can now be relinked
- Cleaned up the visual design of the asset context menu

## UI Features

- All menus and commands now consistently use "Title Case" capitalization and aligned wording
- The graph shows indicator lines for auto-collected clips (e.g. [TimeClipPlayer], [AudioClip]s)
- New **Timeline Follows Playback** setting keeps the current time visible during playback
- New **Select Following Clips** action to quickly grab everything after the current clip
- Added a **Disconnect** context menu entry and keyboard shortcut -- ❤️community
- Restored the legacy right-click-to-select behavior -- ❤️community
- TiXL warns on startup if your projects folder is inside OneDrive and offers to move it to a safer location
- Improved the projects folder settings and restart interaction
- Adjusting timeline layer heights is smoother
- Incrementing animated values (Shift+C) now only affects scalar parameters
- Improved the variable name input for [GetVar] / [SetVar]
- Improved namespace sorting in the Combine dialog
- Improved thumbnail caching and freeing

## Operators

- [MidiClip] has been replaced with the new consistent `DataClip` implementation  (previously called [LoadMidiFile])
- [TimeClipPlayer] auto-collects non-connected time clips
- New audio graph operators: [CombineAudio], [AudioReverb], [AudioDelay], [AudioCompressor], [AudioEcho], [AudioLevel] and [DuckAudioLevel]
- [PlayAudioSample] now uses the audio graph pipeline
- New [Vec2JitterOffset] and an updated TXAA implementation
- [RaymarchField] no longer distorts with camera lens shift
- [SortPoints] now works with non-power-of-two point counts
- [CustomDrawMesh] got improvements and new examples
- [MapPointAttribute] no longer maps attributes twice in repeat modes

## Stability

- Fixed many potential exceptions (file watching, crash reporting, [NdiInput] source names, resizing the RenderView, Vec4 ADSR input, and more)
- NDI works again in exported executables
- Fixed duplicating symbols with namespaces containing keywords like `float`
- Bypassing audio and shader graph operators works correctly
- Avoid endless warning loops when an audio track couldn't be recorded
