The live audio source — microphone, line-in, or system loopback — that a project can react to in real time.

Choose the input device in the audio settings; TiXL then reads its level and frequency spectrum every frame so operators can drive visuals from what's actually playing or being performed. This is the path for reactive live sets, as opposed to a soundtrack file loaded onto the [ui:Timeline]. Pick a loopback device to react to whatever your computer is playing, or a line-in to react to an external mixer or instrument.
