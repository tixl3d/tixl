The startup dialog shown by preview (alpha) builds, which warns that the preview keeps its own separate settings and project folders.

Because an alpha build creates its own versioned settings and project folder, it can't silently corrupt the projects of your stable install — this window is where you understand and manage that separation. Its tabs let you copy configuration and project folders over from a previous version as a one-time migration, and run guided walkthroughs of new features. A "show on startup" toggle controls whether it appears on each launch.
