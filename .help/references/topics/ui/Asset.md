An **Asset** is a media file — an image, video, font or similar resource — that a project loads and feeds into operators.

You browse and manage assets in the [ui:AssetLibrary|Asset Library], and load one into your graph with the matching operator (for example an image loader). Help text and descriptions can link directly to an asset with a square-bracket link, opening it in the library when clicked. For textures that change size on screen, mip-maps let a shrunk copy sample cleanly instead of shimmering — worth enabling on things like textured particles.
