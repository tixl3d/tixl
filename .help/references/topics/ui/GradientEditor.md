The **Gradient editor** lets you build and edit a color gradient, mapping a range of positions to colors for shading, ramps, and lookups.

Alt-click on the gradient band to add a new color key, then drag keys to reposition them and click one to open the [ui:ColorEditor|Color editor]. It pairs naturally with a value curve when you shade many instances across a distribution, for example keying colors to a point's W value so each instance in a cloud picks up its own tint.
