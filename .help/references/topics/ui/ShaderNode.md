A single node inside a [ui:ShaderGraph|shader graph] — one generator, space, adjust, or combine step whose output feeds the next node.

Each node contributes one piece of the [ui:Field|field]: a sphere or box shape, a twist or repeat of space, a color, or a merge of two inputs. Select a node to edit its parameters in the [ui:ParameterWindow|Parameter window] like any other operator, and chain nodes to compose the final field. Because the whole chain compiles into one shader, adding more nodes deepens the shader rather than adding separate render passes.
