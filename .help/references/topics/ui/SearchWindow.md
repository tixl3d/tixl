The **Search window** is a quick finder for jumping to an operator by name, opened with Ctrl+F.

It uses synonyms and fuzzy matching, so "donut" finds [TorusMesh] and small typos still land the right operator. Press Ctrl+F on an empty field to see your recently visited operators as history — arrow-down walks it, and Alt+Left/Right steps through your selection history like a code editor. Type `?` to get a random operator, a fun way to discover unfamiliar ones or set yourself a build challenge.
