Maps what your graph renders onto the displays, projectors and video streams of a real room — for projection mapping, multi-display installations, and sending a canvas to another application over Spout or NDI.

Open it with the **Output Setup** button at the end of an [ui:OutputWindow|output window]'s toolbar, or **Edit Output Setup** in the TiXL menu. The **board** above lays the venue out in metres, while the **flow outliner** below traces the path pixels take: content from each [SendToOutput], cut into slices, mapped onto surfaces, pinned onto outputs, and finally bound to this machine's displays or senders. Only that last column is machine-specific, so a setup you prepare from a photo at home travels with the project and you rebind outputs once on site. Give an output a canvas size of 0 × 0 and it renders at whatever resolution the attached display reports, which lets one setup serve a 1080p screen and a 4K projector.
