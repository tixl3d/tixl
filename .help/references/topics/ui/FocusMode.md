A distraction-free layout that hides the editor's panels and chrome to give the stage a clean, uncluttered view.

Toggle it with F12 (or from the layout menu) when you want to concentrate on the output — for a live performance or focused editing. TiXL remembers which panels were visible and restores your previous layout when you switch back out. It behaves like the numbered F1/F2 layouts, but is reserved specifically for this hidden-chrome view.
