The panel for exporting your composition to a video or image sequence.

Open the **Render settings**, pick a time range and format, and start the render; audio is included in the output. An auto-increment version-number option bumps the filename each time, so with the panel left docked you can re-hit render to save numbered work steps without overwriting earlier ones. Keep an eye on the output resolution, which follows the same rules as the [ui:OutputWindow|output window] unless you set a fixed size.
