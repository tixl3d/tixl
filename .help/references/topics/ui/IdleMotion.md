A mode that keeps procedural animation gently moving even while the [ui:Timeline|timeline] is paused, so a scene never freezes completely when you stop playback.

With it on, operators run against an effect time that keeps advancing during pause, while keyframe-driven time stops with the marker — so noise, oscillators, and other continuous animation drift on while your keyframed motion holds still. It's handy for keeping a preview alive as you work, or for a background that should never look frozen. Turn it off when you need the output to hold an exact frame.
