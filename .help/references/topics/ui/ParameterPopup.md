The **Parameter popup** is the small inline editor that opens on a single parameter so you can adjust it without leaving the graph.

It is where you fine-tune a value directly, including the paired gain-and-bias control found on many operators. That control works like a tone curve: an S-shape adds contrast while an inverse S flattens it, and the bias half pushes values brighter or darker, so one Vec2 covers both shapes across images, distributions, and easing.
