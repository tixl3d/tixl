The **Curve editor** is the [ui:Timeline] view for shaping how a value moves between keyframes, letting you adjust each key's value and tangents directly.

Expand a parameter row in the [ui:AnimationArea|Animation area] to get it embedded and aligned to the dope-sheet. When many keyframes are squashed into a narrow value range and become invisible, auto-scale the curve to the visible keys to make a dense track readable again. Use the "space evenly" command to redistribute selected keyframes by their value differences rather than by uniform time, which helps clean up hand-tapped beats.
