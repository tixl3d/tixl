A long, loose meet-up that starts with a walkthrough of the new output system: central outputs bound to displays, slices, physical-space surfaces, straightening a reference photo, calibrating a projector from reference points, floor plans with pixel maps for an immersive venue, and the new ML beat-detection model. The second half is community Q&A: planning a field-driven quadtree subdivision effect, dissecting a compute-shader point operator as a template for your own, fixing broken mesh tangents in a custom vertex shader, and a blend-able RepeatAtPoints variant.
