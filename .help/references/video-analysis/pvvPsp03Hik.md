A long community meet-up walking through recently merged pull requests (delete-symbol, MSDF font generator, camera-distance point sorting, consistent gradients, render-to-file rework) and live-patching demos of new operators (FastBlur, RemoveStaticBackground, KeepInTextureArray, beat-tapping audio sync); the back third drifts into projection-mapping, licensing, and hardware chatter.

## Mentions
- 4:24→8:14 [FastBlur] · in-depth · discussion · Performance · 88% — A Kawase-style blur that stays smooth where a sample-count blur bands and crawls: roughly 5–20× faster at large radii and clean enough to feed [Steps] for hard posterized gradients without multi-pass tricks.
- 7:39→8:14 [Blur] · passing · discussion · Comparison · 70% — At large radii it artifacts unless you crank the sample count, which gets slow — reach for a Kawase-style blur instead when you need smooth falloff.
- 5:01→6:13 [ImageLevels] · explained · experiment · Example · 72% — Drag the level down to isolate a mid threshold, then widen it to expand a blurred mask — a quick way to turn a soft image into a controllable cutoff.
- 8:21→15:49 [RemoveStaticBackground] · in-depth · discussion · Concept · 85% — Trains a per-pixel statistical model of the empty scene, then outputs only what differs — its debug range visualizes the difference, and a darker-only suppression mode lets you key people in front of a projector without feedback. Disable the camera's auto-exposure first or the model drifts.
- 33:55→39:05 [ui:Symbol] · explained · scripted · Tip · 78% — New MSDF font generator (under utilities) turns any .ttf into a usable signed-distance font written straight into the project's resources/fonts; widen the glyph range for accents/umlauts and raise resolution when you add many glyphs.
- 41:37→43:35 [SamplePointsByCameraDistance] · explained · discussion · Concept · 80% — Sorts a point buffer back-to-front by distance to the active camera so transparent sprites composite correctly; needs a bitonic-style multi-pass (≈70 passes for 200k points) but unlocks correct alpha for huge particle counts.
- 43:35→46:53 [EaseKeys] · explained · experiment · Gotcha · 70% — Eases between keyframes placed directly on this operator (Shift+C to add) — it ignores interpolated values arriving through a connection, so keyframe it in place rather than feeding an animated input.
- 1:13:27→1:17:30 [EaseKeys] · in-depth · answer · Parameters · 82% — Pick the curve via the interpolation dropdown (quadratic, exponential, elastic…); the transition duration comes purely from the spacing between keyframes, not a separate speed knob, and a Constant key is the one type left un-eased.
- 1:17:39→1:25:07 [Grain] · explained · discussion · Performance · 78% — Adds animated film grain but is costly because it samples a per-pixel random texture; pin its animation speed to zero to cut the expense when you don't need the motion.
- 1:17:50→1:23:50 [RadialGradient] · in-depth · discussion · Gotcha · 80% — Reworked to share parameter order and direction with [LinearGradient]; the breaking change is that ping-pong mode is now shifted one period, and it gained an optional dither-noise amount that only costs a buffer when non-zero — switch it on to kill visible banding on smooth gradients.
- 1:25:22→1:29:25 [Warp2dMesh] · in-depth · experiment · Concept · 82% — A four-corner bilinear warp, not a true perspective homography, so a flat image projected onto a surface won't line up from corners alone; add interior control points (e.g. via [BlendPoints] for edge centers) to bend it into place.
- 1:26:04→1:30:00 [TransformPoints] · explained · experiment · Tip · 70% — Stack one on a warp's corner points to nudge an edge outward for curved or lattice-style surfaces when the flat four-point fit isn't enough.
- 1:30:40→1:33:05 [BlendPoints] · passing · discussion · Example · 65% — Used to interpolate an extra control point (a top-edge midpoint) between two corner points so a warp grid gains a draggable handle.
- 2:08:40→2:11:56 [KeepColors] · explained · scripted · Example · 80% — Continuously appends the incoming color into a fixed-length list each frame; drive its input from an [HSLToColor] over time to record a moving hue into a list you can then turn into a gradient or sample randomly.
- 2:11:52→2:12:01 [BuildGradient] · passing · scripted · Example · 62% — Feeds on a recorded color list to assemble a live gradient from sampled colors.
- 2:08:40→2:18:06 [KeepInTextureArray] · in-depth · experiment · Concept · 80% — Records each frame's texture into a growing array (size must be pre-initialized since textures can't resize in place) and exposes both a single read-indexed slice and the whole array buffer — scrub the read index for a manual history, or feed the array out for time-based effects. GPU-heavy at large counts.
- 2:17:29→2:25:00 [TimeDisplace] · in-depth · experiment · Example · 78% — Looks up a frame from a recorded history array by a per-pixel displacement map, smearing motion across time like a slit-scan; note it already contains its own [KeepInTextureArray] internally, so feed it raw video, not a pre-recorded array, and keep the displacement amount large since it counts in frames.
- 2:31:30→2:33:00 [DirectionalBlur] · passing · experiment · Parameters · 62% — Streaks an image along a chosen direction by a set sample count; useful as a building block when faking per-channel RGB smear effects.
- 2:28:49→2:29:09 [ChromaticDistortion] · passing · discussion · Comparison · 60% — Does a chromatic split but bundles it with a radial blur, so it's the wrong pick when you only want a clean per-channel RGB shift.
- 2:39:55→2:40:37 [ChannelMixer] · explained · discussion · Tip · 75% — The cheapest way to isolate a color channel: zero out the channels you don't want — a single shader op rather than the multi-buffer cost of converting to and from a buffer.
- 2:43:57→2:46:51 [RaymarchField] · explained · experiment · Example · 78% — Pipe an SDF plus a color field into its material input to shade the surface by sampled distance; pair with [SDFToColor] and a [TransformField] (animated by [PerlinNoise3]) to map a fractal's distance onto a gradient. Unlike image effects, field nodes compose inside one shader path rather than each allocating a buffer.
- 2:43:13→2:46:51 [SDFToColor] · explained · experiment · Concept · 72% — Maps an SDF's sampled distance through a color gradient so a raymarched surface picks up color from a field rather than a flat material.
- 2:43:57→2:45:03 [TransformField] · passing · experiment · Example · 65% — Rotating/translating a noise field before sampling it (e.g. with a [PerlinNoise3] driving the rotation) animates the pattern that colors a raymarched SDF.
- 4:26:38→4:36:42 [ForwardBeatTaps] · in-depth · experiment · Concept · 85% — Tap-to-beat sync that, once locked, keeps surfing the BPM by ±0.5 to follow a DJ slowing down — giving one continuous never-jumping bar-progress value you can route into any animation; enable beat detection to also place kick/snare/hi-hat onsets.
- 4:26:26→4:29:04 [AudioReaction] · explained · experiment · Tip · 72% — Switch its source to external-device tapping mode for live VJ use instead of the project soundtrack; the colored input-level meter combines left/right channels correctly.
- 1:58:15→2:02:12 [Damp] · explained · answer · Tip · 75% — Feed an audio level through it to get instant attack and slow release (jump up immediately, ease down) — the practical way to get separate rise/fall smoothing from a single reaction value.
- 4:34:33→4:36:34 [ImageFFT] · explained · answer · Gotcha · 72% — Use this rather than the small built-in spectrum when you need a higher-resolution FFT: allocate a bigger buffer and you can analyze finer frequency detail.
- 4:33:52→4:36:00 [SlidingHistory] · passing · discussion · Concept · 60% — Stacking FFT frames into a scrolling history texture is how onset/snare hits become visible as vertical streaks over time.
- 4:27:34→4:31:00 [Blob] · passing · experiment · Example · 58% — Driving its radius/scale from a beat-locked value makes it pulse in sync with detected tempo.
- 4:25:49→4:30:00 [SampleGradient] · passing · experiment · Example · 58% — Reading a beat-synced progress value into it produces a color that cycles in time with the music.
- 0:24→0:54 [SubdivisionStretch] · passing · experiment · Tip · 55% — Quick lazy way to render text to a file and stretch it for an intro card.
- 30:00→33:00 [DrawMesh] · explained · discussion · Gotcha · 72% — A new specular-AA option (on by default) removes the sparkly fireflies on rough/raymarched surfaces — toggle it off to see the ugly aliased speculars it fixes.
- 2:17:37→2:18:06 [MakeTileableImage] · passing · experiment · Example · 55% — A new tileable noise source used as the input texture being recorded into a history array.
