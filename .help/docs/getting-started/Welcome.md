# Welcome to TiXL

TiXL is a visual programming environment for motion graphics, live visuals, and creative coding. You build a graph of operators — each operator does one thing, and the connections between them describe how the final image comes together. The result renders in real time.

This page is your crossroads.

## Pick your path

- **I want to see it first.** Watch the [video tutorials](VideoTutorials.md). Start with the short intro, then follow the full playlist when you have 15 minutes.
- **I want to run it.** [Install TiXL](../install/Installation.md), then open the in-app [Skill Quest](SkillQuest.md) tutorials from the home canvas.
- **I want the concepts.** Read [What is TiXL](WhatIsTiXL.md), then [How TiXL works](HowTixlWorks.md). The terms in [Concepts](Concepts.md) will appear everywhere.
- **I'm coming from Tooll3.** [Migrating from Tooll3](MigratingFromTooll3.md) summarises what changed in v4.

## What TiXL is not

It's not a replacement for [After Effects](https://www.adobe.com/products/aftereffects.html), a general-purpose DAW, or a timeline-based video editor. It overlaps in places with [TouchDesigner](https://derivative.ca/), [vvvv](https://vvvv.org/), and [Notch](https://www.notch.one/), and we'd be happy to help you figure out which fits your project best — ask on the Discord.
