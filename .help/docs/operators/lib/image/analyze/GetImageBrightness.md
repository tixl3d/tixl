# GetImageBrightness

*in [Lib.image.analyze](README.md)*

Analyzes the brightness of a 2D input and outputs the brightness as a float value.
In order to function, this op must be integrated into the active rendering tree.

## Outputs
| Name | Type |
|---|---|
| **Update** | T3.Core.DataTypes.Command |
| **Brightness** | System.Single |
