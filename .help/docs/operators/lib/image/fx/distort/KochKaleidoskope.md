# KochKaleidoskope

*in [Lib.image.fx.distort](README.md)*

This effect is based on Koch snowflake fractal curve.
Angle starts working with Steps set to 2 and above.

For a much simpler version see: [MirrorRepeat] or [TransformImage]

Similar effects or interesting combinations: [MosaicTiling] [VoronoiCells] [SubdivisionStretch]
