# DepthAnythingExample

*in [Lib.io.video.depthanything](README.md)*

Estimates a depth map from an image with Depth Anything 3. Near objects stay bright; switch ModelSizeParam for a larger model or InvertDepth to flip the ramp. The colorized NormalizedDepthTexture is the output.

## Outputs

| Name | Type |
|---|---|
| **Depth** | T3.Core.DataTypes.Texture2D |
