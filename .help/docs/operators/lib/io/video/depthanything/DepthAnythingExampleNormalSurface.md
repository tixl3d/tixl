# DepthAnythingExampleNormalSurface

*in [Lib.io.video.depthanything](README.md)*

Turns a depth map into a normal map and camera-space positions. Wire the normal output into lighting or relighting setups; the position texture holds x, y and distance for point clouds or displacement.

## Outputs

| Name | Type |
|---|---|
| **Normals** | T3.Core.DataTypes.Texture2D |
| **Positions** | T3.Core.DataTypes.Texture2D |
