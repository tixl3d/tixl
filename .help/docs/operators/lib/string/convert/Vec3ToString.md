# Vec3ToString

*in [Lib.string.convert](README.md)*

Converts a Vector3 into a string.

Formats examples: 
({0:F2}, {1:F2}, {2:F2})
Result: 
(0.00, 1.00, 2.00)

X: {0,7:F2}\nY: {1,7:F2}\nZ: {2,7:F2} 
Result:
X:    1.50
Y:    2.50
Z:    3.50
