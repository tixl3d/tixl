# HSLToColor

*in [Lib.numbers.color](README.md)*

Creates an RGBA color from HSL settings

## Input Parameters
| Name (Relevancy & Type) | Description |
|---|---|
| **Hue** (Single) | Normalized Hue (e.g. 0 .. 1 is a full color circle) |
| **Saturation** (Single) | — |
| **Lightness** (Single) | — |
| **Alpha** (Single) | — |

## Outputs
| Name | Type |
|---|---|
| **Color** | System.Numerics.Vector4 |
