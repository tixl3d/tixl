# LastFrameDuration

*in [Lib.numbers.anim.time](README.md)*

Measures how long it took to render the last frame in seconds

Info: Since Vertical Synchronization is activated by default in Tooll, this value is usually limited by the refresh rate of the monitor.
The same value is also displayed at the top of the UI and visualized by a small bar.
Additional information is displayed by hovering.
A left click switches between VSync on / off

## Outputs
| Name | Type |
|---|---|
| **Duration** | System.Single |
