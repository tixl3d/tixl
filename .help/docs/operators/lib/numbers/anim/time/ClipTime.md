# ClipTime

*in [Lib.numbers.anim.time](README.md)*

Returns the current time in Bars.
It is never affected by 'Idle Motion'. This means that when the time is paused, this operator does not count up.
This operator should behave the same as [Time2] with Mode set to 'Playbacktime'.

## Outputs
| Name | Type |
|---|---|
| **Time** | System.Single |
