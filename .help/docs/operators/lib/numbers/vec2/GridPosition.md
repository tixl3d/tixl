# GridPosition

*in [Lib.numbers.vec2](README.md)*

Converts an index to a grid raster position and sizes that can be used to draw a [Layer2d].
This can be helpful for procedural graphical designs.
Please check the example below.

## Input Parameters
| Name (Relevancy & Type) | Description |
|---|---|
| **A** (Vector2) | — |
| **RasterSize** (Int2) | — |
| **Index** (Int32 Required) | — |

## Outputs
| Name | Type |
|---|---|
| **Position** | System.Numerics.Vector2 |
| **Size** | System.Numerics.Vector2 |
