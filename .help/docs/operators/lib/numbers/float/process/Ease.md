# Ease

*in [Lib.numbers.float.process](README.md)*

Note: The input value should evolve by steps (e.g., sudden changes) to fully utilize the easing effect.
This operator creates smooth, ease-in-out transitions between changing input values, perfect for animating any step change. Customize the transition style with options like cubic, exponential, or back easing, or choose a linear fallback for a simple interpolation.
