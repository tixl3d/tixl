# PickFloat

*in [Lib.numbers.float.logic](README.md)*

Picks a value from the connected float inputs.

## Input Parameters
| Name (Relevancy & Type) | Description |
|---|---|
| **FloatValues** (Single Required) | Input for one or more Float values |
| **Index** (Int32) | Selects which of the connected values is used as an output |

## Outputs
| Name | Type |
|---|---|
| **Selected** | System.Single |
