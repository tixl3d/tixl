# SumRange

*in [Lib.numbers.floats.process](README.md)*

Takes a <FloatList> and sums up the values of the given index range limits.
This can be useful for beat detection on an FFT analysis.
Also see [SoundInput], [DetectBpm], [DampPeakDecay].
