# DampPeakDecay

*in [Lib.numbers.floats.process](README.md)*

Compares the current input value to the current damped value. If the input value is great, it is immediately used and no damping applied.
If the input value is small, it is decaying slowly, similar to the peak indicators of equalizer visualizations.
