# DeltaSinceLastFrame

*in [Lib.numbers.floats.process](README.md)*

Returns the change of the value during the last frame (or a given smoothing average).
Please note that this time is not frame-locked and will jitter slightly.

| Name (Relevancy & Type) | Description |
|---|---|
| **Value** (Single) | — |
| **Threshold** (Single) | — |

## Outputs

|---|---|
