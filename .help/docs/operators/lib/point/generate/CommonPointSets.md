# CommonPointSets

*in [Lib.point.generate](README.md)*

Provides a set of useful point lists that can be used to draw shapes, lines and other geometric forms.
[RepeatAtPoints] can be used to distribute these shapes.

[DrawPoints], [DrawLines] can be used to visualize them.

Also known as: Gridpoints, CrossPoints, Crosses, Arrow, Arrows
