# ValueQuiz

*in [Lib.flow.skillQuest](README.md)*

Computes a visual comparison between a "solution" and a "goal" value animation.

Connect your solution to the upper input.

## Input Parameters
| Name (Relevancy & Type) | Description |
|---|---|
| **Yours** (Single Required) | — |
| **Goal** (Single Required) | The reference goal for to current challenge.<br/>Needs to be connected to the (hidden) solution. |
| **DifferenceRange** (Vector2) | — |
| **DisplayValueRange** (Vector2) | — |

## Outputs
| Name | Type |
|---|---|
| **Output** | T3.Core.DataTypes.Texture2D |
