# LoadSoundtrack

*in [Lib.flow](README.md)*

This operator has no function other than to point out that, unlike meshes, images and other assets, audio files are integrated via the "Playback Settings" menu.

This menu can be opened by clicking on the gear icon in the control bar of the timeline. This gives the option to integrate a project soundtrack (for example as an mp3 file) as well as live audio devices.
