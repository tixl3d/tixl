# DrawSphereGizmo

*in [Lib.render.gizmo](README.md)*

Creates a 3D wireframe globe that can be used as a bounding box

## Input Parameters
| Name (Relevancy & Type) | Description |
|---|---|
| **Radius** (Single) | Defines the size of the sphere |
| **InnerRadius** (Single) | Defines the size of an inner sphere consisting of points |
| **Color** (Vector4) | Defines the color |

## Outputs
| Name | Type |
|---|---|
| **Output** | T3.Core.DataTypes.Command |
