# Operator reference

> **Coming soon.** Every operator in the `Lib.*` namespace will have a reference page here, auto-generated from its in-editor description. The generator ([ExportWikiDocumentation.cs](https://github.com/tixl3d/tixl/blob/main/Editor/Gui/UiHelpers/Wiki/ExportWikiDocumentation.cs)) currently writes to the legacy GitHub wiki; the retarget to this directory is tracked in [Plan_UpdateHelp.md](https://github.com/tixl3d/tixl/blob/main/.agentic/Plans/Plan_UpdateHelp.md), Section 4c.

Once active, the URL pattern will be `help.tixl.app/ops/<namespace>/<OperatorName>/` — e.g. `help.tixl.app/ops/lib/field/adjust/PushPullSDF/`. Writers referring to operators in prose just need to use `[OperatorName]` brackets; the auto-linker will resolve them against this reference.
