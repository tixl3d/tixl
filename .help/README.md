# `.help/` — source for the TiXL docs site

This directory is the source of truth for TiXL's user-facing documentation. It ships with the code and publishes to `tixl.app/help/`.

- **Public landing page:** [`index.md`](index.md)
- **Writing style and conventions:** [`STYLE.md`](STYLE.md) — read this before opening a PR that touches docs
- **Plan and open work:** [`../.agentic/Plans/Plan_UpdateHelp.md`](../.agentic/Plans/Plan_UpdateHelp.md)

Developer-focused pages (building TiXL from source, coding conventions, CI, release process) stay on the [GitHub wiki](https://github.com/tixl3d/tixl/wiki). Don't mix the two — if you're documenting something only a contributor opening `t3.sln` would read, put it on the wiki.

## Layout

```
.help/
├── index.md            # site landing page
├── README.md           # this file
├── STYLE.md            # writing conventions
├── general/            # intro, concepts, FAQs, live performance
├── setup/              # installation and dev environment
├── ui/                 # UI reference — timeline, shortcuts, export
├── advanced/           # shaders, custom ops, ArtNet/OSC, perf
└── operators/          # auto-generated from SymbolUi (do not hand-edit)
```

New pages go under the best-fitting section; the section index (`operators/index.md`, etc.) is auto-generated by the MkDocs nav plugin.
